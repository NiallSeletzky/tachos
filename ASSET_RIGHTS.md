The approved TACHOS artwork was supplied for the website, but the creation tool and any third-party inputs/licence conditions should be documented before making strong claims of exclusive copyright or adding an incompatible replacement licence.

The visible website copyright notice identifies TACHOS LTD as the site operator and indicates the year; **it does not override the MIT grant, change third-party rights, or prevent copying a public image**. Any earlier grants remain in force. Do not implement screenshot or right-click blocking and do not infer that technical deterrents confer intellectual property rights.

When provenance is verified, record creator/commission, ownership/assignment where applicable, source assets, creation date, third-party components, approved credit, and usage permissions, then decide whether a separate image licence is appropriate for future releases. A public GitHub repository exposes the source artwork file to download regardless of on-page measures.
