# Tachos design brief

Use `docs/design/LUMINOUS-SYSTEMS-v1.md`, the approved 16 September 2026 reference,
as the canonical visual grammar. This is a versioned copy of
James-Control-Visual-Reference-Architecture-v1.md; source provenance and hash are
recorded in docs/design/README.md. Use TACHOS / Executive Technical mode.

Quiet system, vivid signal: modernist alignment, panoramic calm, dark graphite
and warm parchment, mineral-blue signals with restrained acid-olive accents.
One distinctive element; no generic contractor template, cyber wallpaper,
stock server-rack clichés, vague marketing slogans or competing neon colours.
The production placeholder is accepted temporarily; this foundation does not restyle it.

## Binding website preferences

- Static/composed graphics, no perpetual decorative animation.
- Keep the existing letterhead logo until a replacement is explicitly approved.
  The master guide's final-logo decision remains open; do not silently invent a mark.
- Contact text is simply info@tachos.co.uk and links to mailto:info@tachos.co.uk.
- No street address in the visible placeholder per James's request; legal disclosure
  review remains a separate unresolved company-admin item.
- Direct capability wording; no unsupported accreditation, partnerships or endorsements.
- Typography, negative space and mobile legibility matter more than effects.

## Blender workflow

Keep source .blend scenes outside the deployed repo. Blender retains its own Python;
do not replace it with the Tachos venv. Use the existing Windows installation unless
a concrete task needs Linux Blender; record the actual version when inspected.
Create original panoramic compositions, export a static web-ready image, strip
unneeded metadata, record dimensions/licence/source, and review at mobile and desktop.
Do not add looping video or animation without a new request.
Only an approved export enters assets/ and the public manifest. Update the server
allowlist at the same time if the direct-root deployment is retained.

## Review

Check 390px/mobile, tablet, desktop, 200% zoom, contrast, keyboard focus, alt text,
image loading and composition without motion. Use at most two font families.
Preserve the master guide's ratios and avoid loading remote fonts by default.
